# Interpretação da comparação

Gerado por `python scripts/experiment.py` em `results/comparison.json`.

**Erros** = quantidade de cenários do contrato que falharam. **Violações arquiteturais** = número de achados do scanner AST; os achados são regras explícitas, não equivalem a defeitos em produção. **Intervenções humanas** = `null` (não observadas): não houve execução documentada de agentes independentes.

Os artefatos foram criados deliberadamente para ilustração: **não inferir causalidade** de uma diferença entre eles. Para evidência experimental, executar grupos A/B com múltiplas repetições, avaliador oculto e logging conforme README.
